SIMILE (web) - RELEASE NOTES
============================

Oldest first. The release you are running is shown at the right of the
menu bar. Each release is a date.

The site was first published on 8 August 2026, straight from the
development branch, without separate releases; the first release below
covers everything from then until 13 October 2026.


------------------------------------------------------------------------
Release 2026-10-13
------------------------------------------------------------------------

Running models
- Models run on the Simile engine, with a run control, a plotter of
  variables against time, and a spatial grid.
- Models with submodels and associations run too.
- Simile .pl model files can be imported, and a set of built-in models
  is listed under File > Models.

Building models
- A node properties dialog, with an Equation tab, a tree of Simile's
  functions, and clear messages when an equation is wrong.
- The alarm element is shown, greyed out until it is supported.
  Submodels can have more than one dimension.
- Elements are drawn smaller (70%), with text at the same size.
- Dragging a newly placed element keeps the name you were typing, as
  Enter does.

Windows and files
- Each model opens in its own Model window and Simulation window, with
  titlebars coloured by model. Panels inside a window have a quiet grey
  titlebar.
- View > Windows and Arrange windows are new. Closing a model's window
  closes its simulation window too.
- The current model is shown in the menu bar.
- Each panel is titled with a number, such as diagram/1.
- A small panel shrinks to a thumbnail of its picture.
- File > Export all backs up every model to one file.
- Session > Open as a new user shows the first-run screen in a new tab.
- A clicked window always comes to the front, and a reload keeps the
  order the windows were stacked in.

Touch screens
- Windows and diagrams can be dragged with a finger.


------------------------------------------------------------------------
Release 2026-10-13b
------------------------------------------------------------------------

Tutorials
- Help > Tutorials has the first two of the old Simile tutorials,
  rewritten for the web version: Bank account and Predator-prey.

Building models
- Sketched graphs: a variable or flow has a Graph tab on its properties
  dialog, where a relationship can be drawn by hand and used in the
  equation as graph(x). Graphs in imported Simile models are kept.
- Influence arrows can be selected (they turn blue) and deleted.
- Names must be written with underscores, not spaces; the name box
  says so and suggests one.
- An influence from another submodel is shown with its path, such as
  /S1/a; one from the same submodel by its name alone.
- File > Rename model renames a model, and its windows follow.
- Renaming an element updates the equations that use it.
- The properties dialog's tabs and buttons stay in view while its
  contents scroll.

Running models
- A new time step is used from the next start of a run.
- Run after editing the model loads the edited model first.
- Run settings are remembered for each model.
- Models with capitalised names, or using time(), now run.

Windows and menus
- Choosing a window from View > Windows makes its model current.
- Menu separators are drawn as lines.


------------------------------------------------------------------------
Release 2026-10-13c
------------------------------------------------------------------------

Tutorials
- Help > Tutorials > Trees, the third of the old Simile tutorials:
  modelling a population of trees as individuals.

Running models
- Widgets > Lollipop diagram shows the members of a population as
  lollipops standing on a gridded patch of ground: each at its x and y,
  as tall as its size. Turn and tilt the view with the sliders or by
  dragging; point at one to see its values.
- A plotter draws a variable in a population as one line for each
  member, from when it appears to when it goes.

Building models
- The population symbols are called creation, immigration and loss,
  as in Simile, and models using them can now be run.
- An immigration symbol asks for arrivals per time unit.
- An influence leaving a population is offered in the equation dialog
  as a list, such as {size}.


------------------------------------------------------------------------
Release 2026-10-14
------------------------------------------------------------------------

Live models in your own web pages
- A Simile model can now be put into an ordinary web page, among your
  own text: its diagram, graphs of its results, a lollipop diagram,
  and sliders for its parameters. The model runs as the page opens;
  readers can move the sliders, or edit the model, and see what
  happens. Nothing they do is kept.
- Help > Live models in your own web pages explains how, step by step.
  A page needs one line to bring in Simile, and the model's script.
- File > Export model as script (.js) writes a model, with its run
  settings, as the script such a page loads.
- Two example pages: Rabbits and foxes (pages/predator-prey) and
  A stand of trees (pages/trees).

Building models
- A variable can have a Minimum and a Maximum. A variable with a
  number for its value, a minimum and a maximum, and nothing
  influencing it, is a parameter; Simile .pl files that give these
  keep them on import and export.

Running models
- Widgets > Sliders gives a slider for each of the model's parameters.
  Moving one runs the model again with that value, without changing
  the model; "model values" puts them back.
- A variable added since the model was loaded can be chosen for a plot
  straight away; it is plotted from the next run.
- Lengthening a run no longer makes it slower to fetch: the results
  come back in the same number of pieces whatever the run length.


------------------------------------------------------------------------
Release 2026-10-16
------------------------------------------------------------------------

Models run in your browser
- Models now run in the browser itself, with no server: Simile's own
  tools turn the model into a program in the page, and it runs there.
  SimiLive is used only if that fails.
- The first run of a model in a visit takes several seconds while the
  tools load (about 39 MB the first time; the browser usually keeps
  them). After that a model is ready in about 3 seconds, and going
  back to a version already run is immediate. The page stays usable
  meanwhile; the status line says what it is doing.
- The app remembers the models it has prepared, so on your next visit
  an unchanged model runs at once.
- A run takes milliseconds rather than seconds. Sliders now re-run the
  model as you drag them, starting values included.

Live models in your own web pages
- The example pages come with their models ready to run, so they run
  as soon as the page opens, in the reader's browser. A page without
  that runs too, after preparing the model itself.
- Help > Live models in your own web pages says how this works.

Models
- File > Models has a new model: Pangolin harvest, converted from a
  published R model (Almeida et al., 2023).
- A number written with an exponent, such as 1.0e12, is now exported
  as written; before, the model would not run.
