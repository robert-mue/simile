Getting started: how to build and run a simple model

Tutorial 1 · Level 0 · Bank account. Adapted for Simile on the web from the Simulistics tutorial by Robert Muetzelfeldt.

This tutorial takes you through the basic steps of building and running a model in Simile: drawing the model diagram, giving it values and equations, running it, looking at the results, changing it and running it again, and saving it.

Simple bank account model

We will make a model for a simple bank account, with interest paid annually at a rate of 10%, and $10 taken out every year. The account initially contains $300. This is what we expect to happen:

Year 1
Opening balance$300.00
Interest paid in$30.000.1 × 300
Withdrawal$10.00
Closing balance$320.00300 + 30 − 10
Year 2
Opening balance$320.00
Interest paid in$32.000.1 × 320
Withdrawal$10.00
Closing balance$342.00320 + 32 − 10
Year 3
Opening balance$342.00
Interest paid in$34.200.1 × 342
Withdrawal$10.00
Closing balance$366.20342 + 34.2 − 10

And so on. Note that the increments get bigger each year: each time the balance goes up, the interest paid goes up too. The balance of the bank account increases at a faster and faster rate.

Having understood the calculations we are going to perform, we now turn to the concepts needed to express these ideas in Simile.

We use a stock (called a compartment in earlier versions of Simile) to represent the amount of money held in the bank account, since this is a quantity that changes incrementally over time. We use two flows: one for the gain of money from interest, the other for the loss of money by withdrawal. The interest flow goes into the stock, and the withdrawal flow comes out of it. We also use a variable to represent the interest rate (10%, or 0.1). This variable is linked to the interest flow by an influence arrow, showing that the amount of interest paid depends on the interest rate. Since the amount of interest paid also depends on the amount in the bank account, we also draw an influence arrow from the stock to the interest flow.

In this tutorial we want mainly to introduce you to the mechanics of working with Simile, which are explained in detail in the following steps. The concepts involved in representing even a simple system like this one in a modelling language can be quite complex.

Step 1: Starting Simile: what's on the screen

Starting Simile

Simile on the web runs in your browser: there is nothing to install. Open robert-mue.github.io/simile. Any modern browser will do; Chrome or Edge give you the fullest File menu (see Step 8).

The first time you open it, you see an empty workspace with a menu bar along the top.

Starting a new model

Open the File menu and choose New model.

Two windows appear, both belonging to your new model, which for now is called model.

Naming the model

  • Open the File menu again and choose Rename model….
  • Type Bank account and click OK.

The model's windows, and the menu bar, now use its new name. You can rename a model like this at any time.

The model's windows

Your model has two windows:

  • the Model window, where you draw and edit the model diagram, and
  • the Simulation window, where you run the model and look at its results (you will use it from Step 4).

What's on the screen

  • The menu bar along the top, containing File, some menus specific to Simile, and Help. To its right it says which model is current: the one that commands such as File › Save model act on.
  • Each window has a coloured titlebar. Every window belonging to the same model has the same colour. Drag a window by its titlebar; resize it from its edges or corners. The buttons at the right of a titlebar minimise, maximise and close it.
  • Inside the Model window is the diagram panel. Its first toolbar row has a button for each kind of model-diagram element (ADD), and for each kind of arrow (CONNECT): you use these to build up your model diagram. Hold the mouse over any button to see what it does.
  • The second toolbar row is for zooming and moving around the diagram (VIEW), and for selecting several elements at once (SELECT).
  • The large white area below the toolbars is the canvas. This is where you draw your model diagram.

Values and equations are entered in a properties dialog that you open from an element on the diagram (see Step 3). This replaces the equation bar of earlier versions of Simile.

Step 2: Making the model diagram

We begin by drawing the model diagram for the bank account model. A note on colours: an element that still needs some information (like a value or an equation) before the model can be run is drawn in red. Once it has everything it needs, it turns black. A selected element has a dashed blue box around it.

1. Add a stock to the model diagram

  • Click on the stock button in the toolbar.
  • Move the mouse to the middle of the canvas, and click.
  • You should see a box, with a name box underneath it ready for you to type in.

2. Name the stock "account"

  • Type account, and press Enter.

Immediately after you add an element its name is selected, so you can just type the new name. See section 6 below for how to change it later.

A name is also the name the element has in equations, so it may contain only letters, digits and underscores, and may not start with a digit. Where you would use a space, use an underscore: interest_rate, not interest rate. If you type a name that is not allowed, the name box turns red as you type, and pressing Enter leaves it open, with a message saying what to type instead (see below, in section 4).

3. Add an interest flow and a withdrawal flow

  • Click on the flow button in the toolbar.
  • Move the mouse into some empty space to the left of the stock labelled account, hold the mouse button down, and drag into the middle of the stock. Release the mouse button.
  • Type interest and press Enter.
  • Click on flow again. Move the mouse into the middle of the stock, and drag to the empty space on its right. Release the mouse button.
  • Type withdrawal and press Enter.

A flow that starts or ends in empty space gets a cloud at that end: a source or sink outside the model.

4. Add a variable for the interest rate

  • Click on the variable button in the toolbar.
  • Move the mouse to the empty area above the interest flow, and click once.
  • Type interest_rate and press Enter.

5. Draw the influences

  • Click on the influence button in the toolbar.
  • Move the mouse to the middle of the stock labelled account, and drag an influence arrow to the valve (the bow-tie symbol) on the interest flow. Release the mouse button.
  • Click on influence again. Move the mouse to the middle of the variable labelled interest_rate, and again drag an influence arrow to the valve on the interest flow.

6. Re-arrange the model diagram

  • Move the mouse to the middle of the stock labelled account.
  • Drag it, and watch the stock and its arrows re-arrange themselves.

You can move the other elements in the same way, including the clouds at the ends of the flows. You can also:

  • drag the middle of an influence arrow to bend it more or less. In the picture below, the influence from account has been bent upwards so that it is clear of the flow;
  • drag a name to move it relative to its element;
  • click a name to change it. The new name is carried through to the influence arrows from that element, and to the equations that use it.

This completes the drawing of the model diagram. In the next step you will provide the values and equations needed to simulate the behaviour of the bank account. This order (diagram first, then values) is followed here for convenience. In general you are free to give the values at any stage while you draw the diagram.

Step 3: Adding initial values, parameter values and equations

Every element's value or equation is set in its properties dialog. To open it, double-click the element on the diagram. To close it, click OK to keep your changes, or Cancel (or press Esc) to discard them.

1. Assign the initial value for the stock

  • Double-click the stock labelled account.
  • Enter the value 300 in the Initial value box.
  • Click OK.

2. Add the interest equation

  • Double-click the valve on the interest flow.
  • The VARIABLES list shows the two influences on interest: account and interest_rate. Clicking one inserts its name into the equation where the cursor is.
  • Enter the expression account*interest_rate in the Rate box, either by clicking each variable in turn and typing the * between them, or by typing it all.
  • Click OK.

The FUNCTIONS list beside it holds Simile's built-in functions, grouped by kind. Clicking one inserts it in the same way. You do not need any for this model.

3. Assign the value for the withdrawal flow

  • Double-click the valve on the withdrawal flow.
  • Enter the value 10 in the Rate box.
  • Click OK.

4. Assign the value for the interest rate

  • Double-click the variable labelled interest_rate.
  • Enter the value 0.1.
  • Click OK.

Every element of the model diagram is now black rather than red. This shows that every element has been specified mathematically, so the model is ready to run: Simile has enough information to work out the flows, and so to update the amount of money in your bank account forward through time.

If you type an equation that Simile cannot understand, it tells you what is wrong when you click OK, and offers to take you back to fix it.

Step 4: Preparing to run the model

1. Go to the Simulation window

  • Click on the titlebar of the Simulation window to bring it to the front. If you cannot see it, choose it from View › Windows.

The Simulation window contains the run control, with the controls for running the model, and below it an area called Displays, where the tools for showing model results go.

2. Load the model

  • The MODEL box at the top of the run control already names your model.
  • Click load.

Simile sends your model to the Simile engine, which builds it ready to run. This takes a few seconds. When it is done, the run control says Ready.

3. Change the time step

Simile supplies a default time step of 0.1 when you first run a model. In the natural sciences, a time step shorter than the time unit gives greater accuracy. Here, though, we are dealing with an unnatural example: a bank paying compound interest on the balance of the account at the start of each year.

  • Change Time step(s) from 0.1 to 1.

This is because we want a time step of 1 year rather than 0.1 years.

4. Change the duration of the simulation run

  • Change Execute for from 100 to 10.

This is because we want to run the model for just 10 years at a time.

Step 5: Choosing the output displays

1. Add a plotter

  • Open the Widgets menu and choose Plotter.

A plotter appears in the Displays area of the Simulation window. It scales itself with sensible values on both axes, and rescales as the results come in.

The run settings you typed in Step 4 are remembered for this model, so they are still there whenever you load it again.

2. Choose the variable you want to see

  • In the plotter's toolbar, choose /account from the PLOT list.
  • Click add.

You can add as many variables to one plotter as you like, and remove one again with the × beside its name.

Step 6: Running the model

1. Start the simulation

  • Click the ▶ (Run) button in the run control.

A line appears on the graph, ending at $618.75 after 10 years. The first three years are the ones we worked out by hand: $320, $342 and $366.20. Hold the mouse over the graph to read off values.

2. Continue the simulation

  • Click the ▶ button again.

The simulation carries on for another 10 years, to $1,445.50.

To start again from the beginning, click ■ (Back to the start).

Step 7: Repeating the model edit/run cycle

1. Return to the Model window

  • Click on the titlebar of the Model window, or choose it from View › Windows.

2. Change the interest rate from 10% to 15%

  • Double-click the variable interest_rate.
  • Change its value from 0.1 to 0.15.
  • Click OK.

3. Run the model again

  • Go back to the Simulation window. The run control notices that the model has changed.
  • Click the ▶ button.

The model will automatically rebuild, re-initialise and run again, keeping your run settings and your plot. After 10 years the account now holds $1,010.63.

Step 8: Saving and loading the model

Simile on the web keeps your models in your browser as you work, and they are still there next time you open it in the same browser: open the File menu and choose Models. But to keep a model safe, to move it to another computer, or to give it to someone else, save it to a file.

1. Save the model to a file

  • Open the File menu and choose Save model as file….
  • Navigate to the folder where you want to save the model, in the usual way.
  • Enter a name for the file, and save it.

After that, File › Save model saves straight back to the same file.

Which browser In Chrome and Edge you choose where the file goes, and Save model writes back to it. Other browsers can't do that: they put a copy in your Downloads folder each time instead.

2. Load a model from a file

Either:

  • Open the File menu and choose Open model file….
  • Find your model file, and open it.

or:

  • Open the File menu and choose Recent.
  • Choose from the list of recently used models.
