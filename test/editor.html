Editor regression — gestures on the real diagram widget

Each test builds a model the way a person does — arms a palette tool, presses, drags, types a name — on the real diagram widget, with real pointer and keyboard events dispatched where the press would land (found with elementFromPoint, so what is on top wins, as it does for a hand). Then it checks the model and the drawing. The other pages test the model, the converters and the grammar; this one tests the editor, which they cannot see.

Loaded through embed.js, so the shell's store, actions and undo history are the real ones, and nothing is kept: the page sets SIENNA_EPHEMERAL, and no saved model can be touched. Leave the tab in front while it runs — a hidden tab may not lay out.

Positions are in diagram units at 100% zoom: the stage's view is set to {x: 0, y: 0, k: 1} before each test. Each row shows the diagram as the test left it.
