Fixture regression — round trip and completeness

Every demo fixture is built, converted to Simile Prolog, read back, and the two models compared element by element; then the completeness check is run over it. A fixture must reach a fixed point and audit clean. Unlike roundtrip.html this needs no files: the fixtures are in the repository, so this page is the regression test that survives a wiped scratch directory.

What it is guarding, all of it found the hard way: an exporter that wrote arc(…,undefined,…) for an influence out of a flow; an unquote that stripped the quotes off 'A_Q'*'Gs'; a completeness check that reported the same arrow both undeclared and unused; and a valve whose rate landed on the wrong segment of a cross-boundary flow.
